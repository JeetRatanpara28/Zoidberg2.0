Zoidberg 2.0 - Pneumonia Detection from Chest X-Ray Images

Goals

  • Build a reliable binary classifier for Pneumonia vs Normal chest X-rays.
  • Compare a small set of classical models under the same preprocessing steps.
  • Keep the best-performing pipeline saved for later use.

Tech Stack Summary

Purpose Library
Image loading & processing Pillow, opencv-python
Data manipulation numpy, pandas
Preprocessing & scaling sklearn.preprocessing
Dimensionality reduction sklearn.decomposition.PCA
ML models sklearn (LogisticRegression, RandomForest, SVM, KNN)
Hyperparameter tuning GridSearchCV, RandomizedSearchCV
Evaluation metrics sklearn.metrics
Visualization matplotlib, seaborn
Model saving joblib
Bonus deep learning tensorflow.keras
Bonus SOM minisom
Notebook & export jupyter, nbconvert

Dataset and Setup

  • Dataset structure:
  • Dataset 1: train (data/train)
  • Dataset 2: validation (data/val)
  • Dataset 3: test (data/test)
  • Classes: NORMAL (0), PNEUMONIA (1)
  • Image preprocessing:
  • Grayscale conversion
  • Resize to 128x128
  • Normalize pixel values to [0, 1]
  • Flatten for classical ML models

Methods

Feature Pipeline

  • Standardization with StandardScaler
  • Dimensionality reduction with PCA(n_components=100, random_state=42)

Data Split Strategies

  • Simple train/test split (80/20) from training data
  • The provided train/val/test folders
  • Stratified 5-fold cross-validation (n_splits=5)

Models Evaluated

  • Logistic Regression
  • Random Forest
  • SVM
  • KNN
  • MLP Neural Network

Hyperparameter Tuning

  • Validation-driven tuning using Dataset 2 via PredefinedSplit
  • Parameter grids:
  • Logistic Regression: C, penalty
  • Random Forest: n_estimators, max_depth
  • SVM: C, kernel, gamma
  • KNN: n_neighbors, weights

Evaluation Metrics

  • Accuracy
  • Precision
  • Recall
  • F1 score
  • ROC-AUC
  • ROC curves and confusion matrices

Results Summary

  • All baseline and tuned models were evaluated under the same preprocessing setup.
  • The notebook includes a comparison table with the main metrics.
  • The final choice was made using ROC-AUC, with F1 used as a tiebreaker.

Final Output Artifacts

  • Saved model pipeline:
  • models/best_pipeline.joblib
  • Notebook HTML export:
  • outputs/zoidberg2_pneumonia.html

Conclusions

  • The notebook covers an end-to-end classical ML workflow for pneumonia detection.
  • Model selection is reproducible and based on held-out test data.
  • The project is in good shape for submission and presentation.

Limitations and Next Steps

  • The validation set is very small, so tuning can be noisy.
  • The CNN bonus is not included in this run because of environment constraints.
  • A few sensible next steps:
  • Run CNN in a Python 3.10/3.11 environment with TensorFlow support.
  • Add confidence intervals via repeated stratified CV.
  • Add class-specific threshold analysis for recall-sensitive screening.
